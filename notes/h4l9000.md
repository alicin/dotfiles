      scratchpads, the window rules, qshell's `terminal` setting, Toshy's
      terminal keymaps. Why: kitty's Wayland backend has no wl_touch support
      and no setting for it — irrelevant on this machine, but the terminal
      should be the same one everywhere.
      Kitty is not uninstalled by the pull; drop it whenever you like
      (`config/kitty/` stays in the repo and theme-sync keeps syncing it for
      as long as the binary exists).
