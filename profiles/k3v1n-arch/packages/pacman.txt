# ── Tablet mode ──
# wtype drives zwp_virtual_keyboard_v1, so qshell's on-screen keyboard types
# straight into the compositor. Deliberately not ydotool: that injects through
# uinput, which lands *upstream* of Toshy (xwaykeyz) and would come back out
# remapped -- the OSK would type macOS shortcuts at itself.
wtype
# Runtime screen rotation. `hyprctl keyword` is refused under the Lua config
# parser ("keyword can't work with non-legacy parsers"), but Hyprland does
# implement zwlr_output_management_v1, so this is the way to turn the panel.
wlr-randr
# Reads the hinge/dock switch and (on hardware that has one) the accelerometer.
# k3v1n has SW_TABLET_MODE and an ambient light sensor but no accelerometer, so
# this supplies the first and stays quiet about the second.
iio-sensor-proxy
# bin/osk-focus-watch binds as the seat's zwp_input_method_v2 to learn when a
# text field is focused -- the only source for that fact, since Hyprland's IPC
# has no IME event and Quickshell has no input-method API. The protocol XML is
# vendored (system/wayland-protocols/), because no Arch package ships
# input-method-unstable-v2.xml; this is what scans it into bindings.
python-pywayland
# scripts/theme-sync.sh flips GTK3 apps between adw-gtk3 and adw-gtk3-dark to
# follow the qshell theme (GTK4/Chrome follow the portal color-scheme, GTK3
# needs an actual theme swap).
adw-gtk-theme

# every notification went to dunst instead. h4l9000 does not install it either.

# fnm, but deliberately NOT nodejs/npm/pnpm. scripts/prepare.sh runs before
# this list and already sets the JS stack up: node via fnm, pnpm via its own
# installer. config/zsh/plugins.zsh then evaluates `fnm env --use-on-cd` and
# config/zsh/env.zsh points PNPM_HOME at ~/.local/share/pnpm, so pacman's node
# and pnpm would be shadowed on PATH at best and fight the fnm-managed node at
# worst. Same arrangement h4l9000 runs.
#
# fnm itself does need to come from pacman: prepare.sh installs it with
# `brew install fnm`, and Homebrew left it unlinked in the Cellar with only
# `brew` itself in /home/linuxbrew/.linuxbrew/bin -- so `command -v fnm` failed
# in zsh, the `fnm env` eval never ran, and node was missing from every shell.
# h4l9000 gets fnm from pacman too, which is why it never hit this.
